# Contributing to AI Space-Tech Portfolio

Thanks for helping improve this learning portfolio.

## Workflow

1. Open an issue describing the documentation or project improvement.
2. Create a focused branch from `main`.
3. Keep the change small and explain its purpose in the pull request.
4. Add screenshots or links when a change affects a project page.
5. Check spelling, links, and Markdown formatting before requesting review.

## What makes a useful contribution?

- Clear project descriptions and setup instructions
- Verified demo links and screenshots
- Small improvements to accessibility and responsive behavior
- Learning notes that help another student reproduce the result
- Honest roadmap updates based on completed work

Please avoid adding credentials, private data, or unverified claims to the repository.
